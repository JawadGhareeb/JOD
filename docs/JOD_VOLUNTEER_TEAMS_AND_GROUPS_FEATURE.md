# JOD — فكرة الفرق التطوعية والمجموعات

## الهدف

إضافة مساحة داخل تطبيق JOD تسمح للمستخدمين بإنشاء **فرق تطوعية** أو **مجموعات مجتمعية** حول هدف واضح، مثل مساعدة منطقة، تنظيم فعالية، دعم حملة، مساعدة طلاب، أو تنفيذ نشاط تطوعي مستمر.

الفكرة ليست مجرد دردشة جماعية؛ بل كيان منظم له أعضاء، أدوار، طلبات انضمام، أنشطة، ومنشورات أو مهام مرتبطة به.

## الفرق بين الفريق التطوعي والمجموعة

### الفريق التطوعي

- موجّه للعمل الميداني أو المهام التطوعية.
- له قائد أو أكثر.
- يمكن أن يحتوي على مهام، احتياجات، فعاليات، وسجل إنجازات.
- يمكن ربطه مستقبلًا بحملة أو منظمة أو منطقة.
- العضوية قد تحتاج موافقة من الإدارة.

### المجموعة

- موجّهة للتواصل والنقاش حول موضوع أو مجتمع معين.
- يمكن أن تكون عامة أو خاصة.
- تركيزها الأساسي المنشورات، النقاشات، والتنسيق بين الأعضاء.
- يمكن تطويرها لاحقًا لتصبح فريقًا تطوعيًا إذا احتاجت لتنظيم مهام ميدانية.

## إنشاء فريق أو مجموعة

يقترح أن يحتوي نموذج الإنشاء على:

- الاسم.
- النوع: فريق تطوعي أو مجموعة.
- وصف مختصر وواضح.
- صورة الغلاف وصورة/أيقونة المجموعة.
- المدينة أو المنطقة، إن كانت مرتبطة بمكان.
- التصنيف، مثل: طلاب، غذاء، صحة، تعليم، طوارئ، بيئة، إلخ.
- سياسة العضوية: عامة، طلب انضمام، أو بدعوة فقط.
- الحد الأقصى للأعضاء إن كان مطلوبًا.
- قواعد المجموعة أو الفريق.
- وسائل التواصل الاختيارية.

## الأدوار المقترحة

- **Owner / المؤسس:** صاحب الصلاحية الأعلى.
- **Admin / مدير:** إدارة الأعضاء والمحتوى والإعدادات حسب الصلاحيات الممنوحة.
- **Moderator / مشرف:** مراجعة المحتوى والتعامل مع البلاغات أو المشاكل.
- **Member / عضو:** المشاركة العادية.

في الفريق التطوعي يمكن إضافة دور مثل **Team Leader / قائد فريق** أو **Coordinator / منسق** إذا احتجنا فصل إدارة العمل الميداني عن إدارة المجموعة نفسها.

## تدفق الانضمام

### مجموعة عامة

1. المستخدم يفتح التفاصيل حتى لو لم يكن مسجل دخول.
2. عند الضغط على «انضم الآن» يتم فحص تسجيل الدخول.
3. إذا كان مسجلًا ينضم مباشرة.

### مجموعة تحتاج موافقة

1. المستخدم يشاهد التفاصيل بدون تسجيل دخول.
2. عند الضغط على «طلب انضمام» يتم فحص تسجيل الدخول.
3. يرسل طلب الانضمام.
4. يظهر الطلب للإدارة.
5. عند القبول أو الرفض يصل إشعار للمستخدم.

### مجموعة خاصة

- الانضمام يكون عبر دعوة أو رابط دعوة حسب سياسة المنتج.

## صفحة تفاصيل الفريق/المجموعة

يُفضّل أن تتضمن:

- الاسم والصورة والغلاف.
- وصف الفريق أو المجموعة.
- المؤسس/الناشر.
- عدد الأعضاء.
- نوع العضوية.
- المدينة والتصنيف.
- زر الانضمام/طلب الانضمام.
- قائمة مختصرة بالأعضاء والإداريين.
- آخر المنشورات.
- الأنشطة أو المهام القادمة للفريق التطوعي.
- قواعد المجموعة.

## المنشورات داخل المجموعة

يمكن دعم:

- منشور نصي.
- صور.
- فيديو.
- إعلان إداري مثبت.
- منشور طلب متطوعين.
- منشور نشاط/فعالية.

ويفضّل أن تكون صلاحية النشر قابلة للتحديد من الإدارة:

- جميع الأعضاء.
- الإداريون فقط.
- الأعضاء بعد موافقة المشرف.

## مهام الفريق التطوعي

ميزة مستقبلية مهمة للفرق:

- عنوان المهمة.
- الوصف.
- المكان.
- التاريخ والوقت.
- العدد المطلوب من المتطوعين.
- المتطوعون المقبولون.
- حالة المهمة: مفتوحة، مكتملة، ملغاة.
- إمكانية التسجيل في المهمة.

هذا يجعل الفريق أداة تنفيذ وليس مجرد صفحة اجتماعية.

## الإشعارات

الإشعارات المهمة المقترحة:

- وصول طلب انضمام جديد للإدارة.
- قبول أو رفض طلب الانضمام.
- دعوة للانضمام إلى فريق/مجموعة.
- تعيين المستخدم كمدير أو مشرف.
- منشور أو إعلان مهم من الإدارة.
- إنشاء مهمة تطوعية جديدة.
- قبول المستخدم في مهمة.
- تعديل أو إلغاء فعالية/مهمة.

## الخصوصية والأمان

- المستخدم غير المسجل يستطيع مشاهدة المجموعات العامة والتفاصيل العامة.
- أي إجراء مثل الانضمام، النشر، التعليق، أو التسجيل في مهمة يتطلب تسجيل الدخول.
- المجموعة الخاصة لا تعرض محتواها الداخلي لغير الأعضاء.
- يجب وجود بلاغ عن مجموعة أو منشور أو عضو.
- يجب وجود حظر أو إزالة عضو بواسطة الإدارة.
- حذف الفريق/المجموعة يحتاج تأكيد وصلاحية Owner واضحة.

## البحث والاكتشاف

يمكن إضافة قسم «اكتشف الفرق والمجموعات» مع فلاتر:

- النوع.
- المدينة.
- التصنيف.
- الأكثر نشاطًا.
- الأحدث.
- مجموعات المستخدم.

## التكامل مع ميزات JOD الحالية

يمكن ربط الفرق مستقبلًا مع:

- حملات المساعدة.
- بوستات طلب المساعدة.
- بوستات تقديم المساعدة.
- المساعدات الطلابية.
- مقالات التوعية.
- فيديوهات/ريلز المنظمات.
- الإشعارات.

مثال: حملة تحتاج 20 متطوعًا، فيمكن لمنظمة أو مستخدم نشر المهمة داخل فريق تطوعي مرتبط بالحملة.

## MVP مقترح

النسخة الأولى يمكن أن تتضمن فقط:

1. إنشاء فريق/مجموعة.
2. عرض التفاصيل.
3. قائمة الأعضاء.
4. طلب الانضمام وقبول/رفض الطلب.
5. أدوار Owner/Admin/Member.
6. منشورات المجموعة.
7. الإشعارات الأساسية.
8. مغادرة المجموعة وإزالة عضو.

ثم نضيف المهام التطوعية، الدعوات، الفعاليات، وربط الحملات في مرحلة لاحقة.
